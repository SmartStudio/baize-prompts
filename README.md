## Quick start

1. 先读一条提示词或一个 Skill 的 `SKILL.md`，看它解决哪一步（诊断 / 接入 / 工程 / 交付 / 沉淀）。
2. 复制到你的 Cursor / Claude Code / Codex 技能目录，或直接贴进对话。
3. 没有「安装包」。边界表没签之前，不要用这些提示词去放大自动化。

```
prompts/    可直接粘贴的提示词
skills/     带步骤的 Skill（SKILL.md）
```

目录还在往里填。结构和条目由整理中的提示词库迁入。
