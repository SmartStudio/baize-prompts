## Quick start

1. 按分类打开一条 `prompts/<cat>/<slug>.md`，或一个 `skills/<name>/SKILL.md`。
2. 复制到 Cursor / Claude Code / Codex，或直接贴进对话。
3. 没有安装包。边界表没签之前，不要用这些提示词去放大自动化。

| 路径 | 给谁 |
| --- | --- |
| `prompts/agent-coding/` | 编码 Agent：Codex / Claude Code / Cursor 交接、编排、审计 |
| `prompts/product-strategy/` | 产品策略 / 商业计划 |
| `prompts/research-pkm/` | 研究与知识库维护 |
| `prompts/marketing-sales/` | 营销销售 |
| `prompts/review/` | 评审验收 |
| `skills/` | 验收后升格的可重复技能，每技能一个目录 + `SKILL.md` |

每条提示词最少四段：**用途 / 何时不用 / 边界（人必须批准什么） / 原文**。来源 URL 放 frontmatter。不收客户名、密钥、图视频提示词。

现在公开的是目录骨架。精选条目随验收入库，不倒半成品。
