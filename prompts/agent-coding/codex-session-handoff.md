# 把长会话安全交给下一棒

长会话该换了，现场不能跟着断。

## 原始问题

普通交接笔记能写现状和待办，却常漏掉未提交改动、新会话命名和无法自动建会话时的降级动作。测试要看一条 Prompt 能不能把这些安全边界一起钉住。

## 给模型的输入

这段输入根据 A/B 摘录重建，不是官方逐字原文。原始 scratch fixture 已缺失，仓库状态、Git 状态、代码改动和测试结果无法重建。

```text
当前 Codex 会话上下文过长，需要安全迁移到新会话。

[缺失：scratch fixture 的仓库状态、Git 状态、代码改动、已完成与未完成任务、关键决策、风险和测试结果。]
```

## 复制这条 Prompt

把真实项目现场和下面这段 Prompt 放进同一条消息，再发送。

```text
当前 Codex 会话上下文过长，请执行一次安全迁移：

先暂停开发，检查当前仓库、Git 状态、代码改动、已完成与未完成任务、关键决策、问题风险和测试结果，并整理到 .codex/SESSION_HANDOFF.md。不要写入密钥，不要执行 reset、clean 或覆盖现有代码，确保未提交修改安全保留。

然后创建一个全新的 Codex 会话，不要复制旧会话全部上下文。新会话命名为：

【项目名｜续开发｜阶段 2】

并将其置顶。若无法自动新建、命名或置顶，请如实说明，并输出一段可直接粘贴到新会话的启动提示词。

新会话启动后，先读取交接文件、AGENTS.md、README.md，检查 git status 和当前代码现场，确认无误后直接从最高优先级的未完成任务继续开发。

不要重复已完成的工作，不要重新询问已经确认的信息，并如实汇报测试、构建和验证结果。
```

## 跑完会差在哪

完整运行文件当前不在工作区。下面照录 raw 里的真实评测摘录，不冒充模型完整输出。

### A：裸跑

A 使用中性「请完成任务」。

> 通用交接笔记（概况/现状/规则/待办）
>
> 提了不 reset/不泄密，但未钉会话命名/置顶降级

### B：加上 Prompt

> 强制 6 节 SESSION_HANDOFF + 无法建会话声明 + 可粘贴启动词
>
> 完整遵守：不写密钥、保留未提交、降级给启动词

A 能留下交接笔记，但新会话还得人重新组织。B 加了固定交接结构和可粘贴启动词，自动建会话失败也有下一步。摘录内没看到密钥或编造结果。

## 什么时候别用

任务已经结束，或会话仍短且现场简单时，不必做完整迁移。含密钥、客户数据和未脱敏日志的现场也不能直接写进交接文件。

## 人要检查什么

先看 `git status`，确认未提交修改还在。再核对已完成事项、未跑检查和风险，别让新会话把推测当事实。创建、命名、置顶和继续开发都要服从当前工具权限。

## 四维评测

| 维度 | A：裸跑 | B：加上 Prompt |
| --- | --- | --- |
| 结构 | 通用概况、现状、规则和待办 | 固定交接结构，加失败声明和启动词 |
| 约束 | 提到安全，但没钉命名和降级 | 保留未提交改动，不泄密，不做破坏操作 |
| 胡编 | 摘录内未见新增事实 | 摘录内未见新增事实 |
| 可执行性 | 能续，仍要手工整理新会话 | 启动词可直接粘贴，仍需核对现场 |
